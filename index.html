01｜兩年研究歷程

高一｜受傷

暑假約 8 月右膝 ACL 受傷。復健期間無法正常深蹲、跳躍，跑步與高速動作受到限制。

高二｜復健銜接重訓

逐步回到重量訓練。每週約 3 天、每次 1–2 小時，包含哈克機、硬舉、深蹲、慢跑、腿後側彎舉與膝伸展。

高三｜形成研究問題

力量與跳躍能力進步，但高速衝刺與 400 公尺仍未完全恢復，因此開始深入研究 Return to Sport。

03｜研究核心

肌力恢復

探討下肢肌群與漸進阻力訓練在 ACL 復健中的角色。

神經肌肉控制

理解「有力量」為什麼不等於能安全落地、減速與變向。

增強式訓練

探討跳躍、著地緩衝、離心減速與再發力。

功能性評估

不能只用受傷時間或單一重量判定恢復。

04｜Return to Sport

Panther Symposium ACL Injury Return to Sport Consensus Group 將重返運動視為連續過程。

1

Return to Participation

重新參與部分訓練。

→
2

Return to Sport

回到原本運動項目。

→
3

Return to Performance

回到預期運動表現。

力量恢復 ≠ 完全重返專項表現

05｜ACL 功能追蹤示範工具

輸入同一項單腳測試的左右側數值。按下一步後，系統會自動帶入 Recovery Tracker，不需要重新輸入。

請輸入相同測試、相同單位的數值。

單一 LSI 數字不能證明完全康復或可以安全回場，正式回場仍需專業評估。
